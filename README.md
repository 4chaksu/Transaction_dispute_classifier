# Transaction_dispute_classifier
 This Streamlit app classifies customer disputes into categories using OpenAI's GPT model, assigns priority levels, and provides recommended actions based on the dispute type.

## Features
Classifies disputes into categories: Unauthorized Transaction, Duplicate Transaction, Amount Error, and Product Not Received.
Assigns priority (High, Medium, Low) based on the category.
Flags high-risk disputes and provides recommended actions.
